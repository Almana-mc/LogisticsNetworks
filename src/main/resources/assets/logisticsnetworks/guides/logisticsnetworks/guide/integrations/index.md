# Mod Integrations

Logistics Networks works alongside several other mods. These pages cover the ones that change how you play — each integration only switches on when that mod is installed.

- [ComputerCraft](computercraft.md) — read networks, nodes, the node graph and live I/O telemetry from Lua scripts and monitors.
- [Building Gadgets](building-gadgets.md) — move nodes with the Cut and Paste gadget, and copy their settings with Copy and Paste and templates.

## On Minecraft 1.20.1

This version runs on Forge, and a few integrations differ from the Minecraft 1.21.1 version:

- **EMI** drags items and fluids onto filters. Mekanism chemicals drag from JEI only.
- **Ars Nouveau** source moves between blocks that store source, such as source jars. With Ars Énergistique, a node on an ME Source Jar or a Source Acceptor reaches the source in the whole ME network.
- **Create** needs 6.0.8 or a later 6.0.x version.
- **Building Gadgets 2** needs 1.0.8 or a later 1.0.x version.
- **ComputerCraft** needs CC: Tweaked 1.105.0 or newer.
- **Jade** shows the attached-node line only on blocks that have a block entity, such as chests and machines.
- **Sable** and Create Aeronautics are not available.
