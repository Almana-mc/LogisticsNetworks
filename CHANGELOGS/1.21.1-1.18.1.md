## Feature Additions

- The graph editor has a Channel button: cycle All and 0-8 to show only the nodes and links on that channel. Every node shows an S (sender), R (receiver) or S/R badge for the channels on screen (#167)
- Networks named with a slash are grouped: "Base/Furnaces" and "Base/Smelt" sit under a Base header in the node's network picker and the Computer's network list. Click a header to fold it; searching opens every group with a match (#138)
- New client option Side From Clicked Face: placing a node from the node item or by shift-placing with the wrench sets every channel's side to the face you clicked. Mass placement still uses Up (#163)
- New common config `alignChannelDelays` (off by default): channels run on shared tick boundaries, so channels with the same delay transfer on the same tick. This can cause tick spikes on big bases, which is why it is off by default (#200)

## Bug Fixes

- Match Any: a resource now passes if any whitelist lists it, or if the channel has a blacklist and no blacklist lists it, so a whitelist of exceptions beside a broad blacklist works. Several blacklists still block everything on any of them; Match All is unchanged (#184)
- Upgrade warning for #184: existing Match Any channels that mix a whitelist and a blacklist now move everything the blacklist doesn't list; use Match All to keep only the whitelist minus the blacklist. In Match Any a slot-mapped whitelist entry next to a blacklist no longer restricts slots, and a Recipe Card channel with a loose whitelist plus a blacklist sends every item the blacklist doesn't list through the loose lane (#184)
- A blacklist beside a Recipe Card no longer opens the card channel to loose items (#197)
- Networks no longer stop until a block update after a transfer error, and slot-mapped inserts no longer crash or void items in Titanium machines such as the Industrial Foregoing Potion Brewer (#182)
- Slots under open node screen overlays no longer react to clicks, hotbar keys or tooltips (#199)
- With attack and use swapped, LN interactions no longer also break the block. While an LN item (wrench, node, filter...) is in either hand, you aim at a Computer, or the worn wrench is drawn, that button only does LN's Secondary Interaction; rebind Secondary Interaction in Controls to change it (#185)
- Off-screen wrench flow lines now honour maxRenderedNodes and rescan less often, fixing big FPS drops on large builds (#196)
- Graph editor route tooltips now number channels from 0, like the node screen
