## Security

- Fixed a server exploit where a modified client could put any item into a node's filter or upgrade slots and get it back by breaking the node

## Feature Additions

- Added redstone mode "Ignored", which is now the default
- Added distribution mode "Priority Robin": each send goes to the next receiver, cycling from highest to lowest priority
- Renamed distribution mode "Round Robin" to "Equal Distribution". It now splits what the sender actually has across every receiver, for items, fluids, energy, chemicals and Source, so 10 items over 10 receivers gives 1 each
- Raised the default item and fluid batch limits for every upgrade tier. Existing `upgrades.json` files keep their values; delete the file to get the new defaults
- Imports now respect a filter entry's slot mapping: items for a mapped entry only go into those slots
- Stock with a slot mapping now counts only the mapped slots
- Every interaction now uses rebindable keybinds under Controls → Logistics Networks: Modifier Keys 1–3, Primary Interaction and Secondary Interaction
- Added a slot number overlay for container screens, toggled with Alt + I
- New client config option to invert the wrench copy/paste controls
- Networks now have a colour. Networks from older worlds get a random colour the first time the world loads, and keep it
- Networks remember when they were created. Networks from older worlds get a creation time the first time one of their nodes is opened
- Added the common config option `nodeAccessMode`: `Teams` (default: the owner and FTB Teams teammates), `Allies` (also FTB Teams allies) or `All` (everyone). It is also in the config screen
- Added admin mode: `/logisticsnetworks admin` (or `/ln admin`) toggles it for an operator, and `/logisticsnetworks admin mode <player>` toggles it for another player. It ends when the player logs out
- Added the client option "Default Node Visibility" for newly placed nodes
- Labels now keep a shared template of their channels and upgrades. Labelled nodes share upgrade changes, taking the upgrades from your inventory, and nodes that were unloaded catch up with edits when they load
- Toggling a labelled node's visibility now applies to the whole label
- Pasting a clipboard onto a node with a label now applies the label's current settings
- Filters are now virtual: nodes no longer hold filter items. Click an empty filter slot in the node screen and choose Normal, Mod or Regex to create one, or click a filter slot while holding any item to add that item to it
- Each channel now has 6 filter slots, and normal filters hold 45 entries
- New node screen. The network list can be sorted (New→Old, A–Z, Z–A, Old→New), each network has an Edit button for its name and colour, and creating a network asks for confirmation (client option "Confirm Network Creation")
- Labels can be deleted from the label picker. If the label is in use, a confirmation shows how many nodes use it
- Batch, priority and delay fields accept arithmetic such as `64*7`
- Channel tabs are tinted by resource type
- Changing a channel's resource type now clears its filters
- The Computer is now a two-block desktop. Holding one shows a white hologram where it will go, and both halves share one outline. Computers placed in older worlds keep working; break and place them again to get the second half
- Networks in the Computer can be pinned to the top of the list with the star, searched by name, and deleted with the trash button. Deleting returns the nodes and their upgrades to your inventory, and is refused while any of the network's nodes are unloaded
- Redesigned the Computer's I/O Monitor: every channel on one page with live rates, a bar chart (30s / 1m / 2m), and a breakdown of exactly which items, fluids and chemicals are moving
- Added a Graph Editor to the Computer to see and arrange a network's nodes. Ctrl + click and Shift + drag select several nodes, which can then share a label, and node types can be hidden from the legend
- The Computer's node table can select several nodes and apply a label to all of them, or select every node on the same block. A node opened from the table has a "Back to table" button
- Networks can be saved to `.lnet` files in `config/logistics-network/networks` and loaded back: loading copies one label's settings, including its filters, onto the Computer's wrench
- New filter editor. Hold Left Control (Modifier 2) and click an entry for its detail page: batch, stock, slot mapping, tags, NBT rules with categories, raw NBT and strict NBT
- Filter entries match item NBT exactly by default ("Strict NBT"); turn it off on the entry's detail page. Entries in filters from older versions keep matching loosely
- Filters can be copied and pasted between filters, and a node's filter can scan the attached storage to add everything in it
- Added a tag picker with search, sorting and a contents view, including Mekanism chemical tags
- Any-fluid and any-chemical entries, and entries with only a batch or stock
- Hovering a node's filter button shows its entries
- Senders can rotate through their filter's resources one per operation ("Round-robin resources" in the filter editor)
- New clipboard editor: rename channels, pick the network and label, open the clipboard's filters, and drop items (also from JEI) onto filter buttons
- Pasting a clipboard now lists the missing upgrades in chat, and replaced upgrades that don't fit in your inventory drop at your feet
- Regex filters can match tooltips on dedicated servers too
- JEI ingredients can be dragged onto node and clipboard filter buttons
- Added a wrench mode wheel: hold R, point at a mode and release. Modifier 1 + scroll still cycles modes
- Added wrench settings (G, or `/ln wrenchColor`): colour the wrench's case and screen, and set up its flow lines
- Holding a wrench shows animated flow lines from senders to receivers, coloured by resource type. Each wrench has its own settings: Routed or Direct lines, which resource types, channels and network to show, thickness, speed, opacity, pulses, nodes outside the screen, and drawing through blocks
- Nodes next to each other now render as one connected model (client option "Connected Node Textures")
- Holding a wrench shows a node's label under its network name, and the box around each node uses its network's colour
- Mass placement now works on an area: use the wrench on two corners, then open the mass placement screen (Modifier 1 + use, or use in the air) and pick which block type gets nodes. Up to 2048 nodes in an area of up to 10,000 blocks
- New textures for upgrades and the wrench
- Added a built-in "Original Textures" resource pack that restores the old upgrade and wrench textures
- Logistics Nodes can be worn as a cosmetic helmet; drag one into the helmet slot
- Crafting a wrench on its own resets it: mode, clipboard, link, colours and flow settings are cleared
- Added the Network Upgrade, crafted from AE2 parts. A node holding it on an ME Interface reaches the whole ME network for items and fluids; when the network can't fill a batch, the Interface's own slots make up the rest
- Modifier 1 + use an AE2 controller with the wrench to link it, and again to unlink. The tooltip and the wrench HUD show the link as "[AE2]". Wrenches linked in older versions keep their link
- Modifier 1 + use the wrench on an inventory to place a node. The node comes from your inventory, then from the linked ME network, and is otherwise autocrafted there and placed when it is done; an orange outline marks queued spots
- Empty upgrade slots in the node editor show a "+" while a linked network is in reach: click it to pull an upgrade from the network or autocraft it
- Mass placement, clipboard paste and label upgrade syncing take missing items from the linked network; mass placement and label syncing autocraft what is missing

**WARNING: Redstone modes "Always On" and "Always Off" have been removed. Channels set to Always On now use Ignored, and channels set to Always Off are turned off and set to Ignored.**

**WARNING: Operators no longer bypass node and network ownership automatically. Use `/logisticsnetworks admin` instead.**

**WARNING: Regex filters now accept only a safe subset (no groups, quantifiers such as `*` or `+`, or letter escapes) and at most 128 characters. Saved patterns outside it are kept but match nothing until edited; the filter editor marks them.**

**WARNING: Mass placement now selects an area instead of single blocks. Blocks selected with the old wrench are ignored, and cleared the first time you set a corner.**

**WARNING: Filter items are retired. They can no longer be crafted, breaking a node no longer drops its filters, and clipboards no longer use filter items. Channels keep up to 6 filters. Extra filters, and any Tag, Amount, Durability, NBT or Slot filter in a node, drop next to the node the first time it loads.**

## Bug Fixes

- Changing a channel's resource type now resets its batch to the type's limit for the node's upgrade tier
- Upgrading a node now raises every channel's batch to the new limit; downgrading lowers it
- Energy channels always run at the batch limit of their upgrade tier
- Fixed nodes on Mekanism multiblocks (and other late-forming storages) not transferring after world load until toggled
- Nodes can no longer be moved by `/tp`, `/teleport`, `/spreadplayers` or other mods' teleporters
- Logistics Nodes no longer show up as entity dots on minimap radars
- Reduced the hitbox of nodes so they no longer get in the way of interactions
- All Flux Networks blocks are blacklisted from access to the nodes
- Open node screens now update when the network's labels, name or colour change, and channel names show straight after picking a network
- Networks whose saved data can't be read are now kept and saved back unchanged instead of being dropped
- Pasting a clipboard can no longer join a network you don't have access to
- Nodes placed with mass placement are now owned by the player who placed them
- Node screens opened from the Computer now close when you lose access to the node
- Nodes and filters with very large settings now open their screens instead of failing silently
- Filters opened on far-away nodes from the Computer now show their entries
- Cleared filter entries no longer come back after reopening the filter
- Escape in a node's filter returns to the node screen
- Slot mappings set in the filter editor are no longer lost when the filter closes
- Fixed the wrench HUD (H) and slot number (Alt + I) keys doing nothing
- Mass placement no longer uses up nodes and upgrades when it can't place every node; they are given back, and the placed nodes leave their network again
- Nodes held back by the rendered-node limits show again straight after changing dimension
- With Oculus, node highlights, the mass placement outline and the desktop hologram are drawn after the shader pass and skip the shadow pass
- Clipboard paste and mass placement no longer apply upgrades the linked AE2 network did not hand over

## Technicals

- Improved performance by caching network setup between ticks
- Neighbour block updates now wake networks without rebuilding them
- Network protocol bumped; clients and servers must both update
- The client now tells the server which modifier keys are held, so wrench actions follow your keybinds instead of sneaking
- Node screens receive the whole node state when they open, so nodes opened from the Computer show their settings even when they are far away
- Removed the network packets of the retired filter items
- The Computer has a block entity that stores its pinned networks and its owner
- I/O telemetry covers all nine channels at once and names resources through a per-viewer dictionary
- Graph layouts are saved with the network
- Large telemetry, graph and export packets are capped so they can't exceed Forge's packet limits
- NBT rules only read the item data they reference, instead of copying the whole item for every check
- Filter entries are capped at 2 KB of item data, and NBT rules at 8 per entry with size limits
- Clipboard edits send only the settings to the server; filters are changed by the server
- Server work queued from a client packet is skipped if that player has disconnected
- Nodes sync which of their channels send and receive, for flow lines
- Wrench colours, flow settings and the mass placement area are stored on the wrench
- Wrench links are saved as `storage_link` (backend and position). The old `ae2_link` is still read and is replaced on the next change
- Label templates remember the storage network they take upgrades from
- Pending crafting requests are cancelled when the server stops, and their items go back to the network or the player
