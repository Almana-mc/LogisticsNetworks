## Mod Integrations

- Refined Storage now directly links with mod, sneak click a controller to link
- Applied Energistics integrations has been improved

## Feature Additions

- Nodes can be placed by shift right clicking an inventory with a wrench in wrench mode.
- Nodes will be pulled directly from the AE or RS network if placed using wrench
- Nodes can be autocrafted if recipe and resources exist in AE or RS network
- Upgrades can be pulled directly from your AE/RS network or be autocrafted directly from the node GUI
- Mass placement can now also request crafting of nodes or pull directly from AE/RS network
- Mod now can directly interface with AE/RS network bypassing the slot limitations of interfaces
- New config option to invert copy-paste behaviour in client config
