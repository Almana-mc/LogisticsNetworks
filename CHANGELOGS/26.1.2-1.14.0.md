## Feature Additions

- Channels can now carry items, fluids and energy at the same time. The Type row is now Resources: switch each kind on or off and give it its own batch. New channels carry everything they can; existing channels keep their old type
- Filters now hold items and fluids together, and a whitelist only limits the kinds it lists
- Filter entries can now set a Side on their advanced page: the face of the receiving block that item or fluid goes in through, so one channel can feed a furnace ore on top and coal on the side. A side on a receiver's filter wins over the sender's
- Added the Recipe Card: write a recipe on it (JEI + button or by hand) with items and fluids, put it in any filter like any other entry, and the channel sends only whole recipe sets (every resource together) in every distribution mode, with an optional Blocking mode. The card's kinds must be switched on in Resources at both ends, and whole sets per operation are set on the Recipe sets line of the Resources popover
- Recipe Card ingredients have a pencil that opens the same advanced page as filter entries: choose the receiving side for items and fluids, require exact NBT (the default) or set NBT rules, and list receiver slots for items with Split to share the count evenly, so machines like the vanilla Crafter get an exact layout
- Recipe Cards can copy an AE2 or Refined Storage pattern: hold an encoded pattern and click the new pattern slot to fill the card with its items and fluids
- ComputerCraft: getChannels entries and watch samples gain `types`, and samples gain `totals` per type; `type` and `total` now describe the first type
- Added a built-in "Original Textures" resource pack that restores the pre-1.17.1 upgrade and wrench textures
- Added sounds for button click's in mod's GUIs
- Nodes with a Network Upgrade on an AE2 ME Interface that has nothing configured can now pull anything from the whole ME network. Configure the Interface to limit what they can take (thanks Qther)
- Removing a node with the wrench or by breaking the block it sits on now puts the node and its upgrades straight into your inventory, dropping only what doesn't fit (thanks Qther)
- Creative players no longer use up nodes when placing them with the wrench, or upgrades when pasting a wrench clipboard (thanks Qther)
- New Logistics Node look: a flat frame texture on the item, the helmet and placed nodes, with connected nodes outlined as one shape (#126)
- Netherite energy channels now move up to 137,438,953,408 RF per tick instead of 2,147,483,647, shared across the channel's receivers. An existing Netherite Energy Batch of exactly 2147483647 in upgrades.json is rewritten to the new maximum on load. Admins can set it higher so several receivers add up, but one sender and receiver pair stops at about 137 billion RF per tick, and so does a whole Equal Distribution channel
- Added Curios support: wear the wrench in the new Logistics Wrench slot and press K to use it as if it were in your hand, without giving up a hotbar slot
- Hovering a filter in the node editor or the clipboard now shows its entries as icons

## Bug Fixes

- Logistics Nodes no longer show up as entity dots on Xaero's Minimap and World Map radar (#148)
- Nodes joining a label now get the label's latest settings instead of the ones it had when it was created (#149)
- Block icons in the graph editor no longer draw on top of the node hover tooltip
- Labeled nodes that were unloaded while the label was edited now pick up the changes when they load
- Pasting a wrench clipboard onto a node now gives it its label's current settings instead of the clipboard's
- Crafting a wrench on its own now resets it, clearing a storage link left behind by a removed AE2 or RS network (#153)
- Improved performance when exporting from large inventories to many filtered receivers
- Equal Distribution now splits what the sender actually has instead of the full batch size, so 10 items over 10 receivers gives 1 each instead of all 10 to the first
- Equal Distribution now splits fluid and energy channels too, instead of acting like Priority
- Number keys now swap hotbar items into the node screen's slots, so upgrades can be hotkeyed in (#171)
- Text typed into the priority, tick delay and label boxes is now readable in light themes such as Brutalist (#161)
- Network Upgrade now works on ExtendedAE's Extended Interface part (#170)
- Network Upgrade now works on Cable Tiers interfaces, so they reach the whole Refined Storage network instead of only their own buffer
- Improved server performance on large networks: nodes on an AE2 ME Interface no longer re-read the whole ME network on every pass (newly stored items and amounts show up one tick later), redstone and receivers are only checked for channels that are due to run, and energy lookups are cached per pass
- Stock amounts on a node with a Network Upgrade now only check what the Interface itself holds instead of the whole storage network, which caused heavy lag. A Sender needs more than the Stock amount in the Interface to move that resource, and a Receiver stops once the Interface holds it
- The game no longer refuses to start with Building Gadgets 2 26.1.2.3 installed
- Building Gadgets 2 can no longer cut, copy or destroy the Computer and Logistics Server
- Nodes now pull finished potions out of Brewing Stands when async planning is on (thanks julian-perge)
- The invert copy/paste setting now also applies when clicking a node's block with the wrench
- An export and an import node on the same tank no longer pump fluid into that tank itself
- The Max visible nodes setting now limits how many nodes are drawn
- Connected node textures now join nodes whose faces line up, such as a slab on top of a full block
- With connected node textures off, nodes on partial blocks draw as a full cube
- The upgrade picker title names the AE2 or Refined Storage backend
- Selected text is now visible in the config screen's number fields
