# LogisticsNetworks 2.0.0

This release unifies development for Minecraft 1.20.1 Forge, 1.21.1 NeoForge, and 26.1.2 NeoForge under one Stonecutter project.

- Adds `/logisticsnetworks removeInvalidNodes` for safe orphan cleanup.
- Preserves each target's existing world, config, network, and item data formats.
- Uses the 26.1.2 implementation as the authoritative feature baseline.
- Builds target-specific jars with isolated loader metadata and resources.

Optional mod support remains target-dependent because published APIs differ between Minecraft versions.
