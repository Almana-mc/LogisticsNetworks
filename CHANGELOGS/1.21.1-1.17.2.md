## Feature Additions

- Renamed the Server Rack to Logistics Server
- The Logistics Server is now craftable: echo shards, a crafter, crying obsidian, a Computer, netherite ingots and a nether star
- Source channels now work with Ars Énergistique: a node on an ME Source Jar moves source to and from the whole AE2 network
- A node with a Network Upgrade on an AE2 Interface can also move source through the network. It only exports source when Source is set in the Interface config
- Source channels now use Ars Nouveau's source capability, so more source blocks can hold a node
