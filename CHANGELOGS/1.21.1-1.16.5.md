## Feature Additions

- Added redstone mode "Ignored" which is now the default
- Added simple math (like `64*7`, `64+1`) to batch, stock, priority and delay fields
- Mod now supports building gadget's copy paste, cut paste and schematic system
- Added distribution mode "Priority Robin": each send goes to the next receiver, cycling from highest to lowest priority
- Added sorting to the network picker: New→Old (default), A-Z, Z-A and Old→New. Networks from older worlds get a creation time the first time one of their nodes is opened
- Redesigned the Computer's I/O Monitor: every channel on one page with live rates, a modern bar chart (30s / 1m / 2m), and a breakdown of exactly which items, fluids and chemicals are moving
- Added ComputerCraft support: a CC computer next to the Computer can read networks, channels, nodes, the node graph and live I/O telemetry
- Regex filter can match tooltips again (Name / Tooltip / Both); tooltip text is built safely on the server so mods with client-only tooltip code no longer crash dedicated servers (#83)
- Flow line settings moved from the mod config onto the wrench (press G): every wrench has its own line colors per resource type, Routed or Direct lines, and filters for resource type, channel and network. Lines can now reach nodes that are off-screen or too far away to render

## Bug Fixes

- Improved performance for certain interactions with MI
- Stock filter now checks for specific slots when combined with slot filtering option
- Fixed nodes on Mekanism multiblocks (and other late-forming storages) not transferring after world load until toggled
- Fixed node culling
- Labels now sync node visibility (visible/hidden) across all nodes sharing the label
- Renamed distribution mode "Round Robin" to "Equal Distribution"

## Technicals

- Reworked internals to be component heavy
