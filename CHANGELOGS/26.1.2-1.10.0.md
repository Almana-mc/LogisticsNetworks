Combined applicable updates from the 1.21.1 releases 1.10.0 through 1.14.2.

- Added multithreaded item transfer planning, with bounded queues, stale-plan checks, and synchronous fallback.
- Added configurable team, ally, or public access for nodes and networks.
- Added a "Scan attached storage" button to fill filters with items or fluids from the connected storage.
- Recolored filter UI icons for better visibility.
- Replaced hardcoded interaction controls with remappable keybinds.
- Improved Sophisticated Core compatibility, including bulk insertion, partial acceptance, and upgraded storage slots.
- Reduced repeated bulk insertion checks by caching rejected transfers.
- Fixed Round Robin distribution so items are shared between destinations instead of behaving like Priority mode.
- Fixed item transfers between nodes attached to the same storage, including opposite halves of a double chest.
- Made ordering consistent for nodes with equal priority.
- Improved filter processing by stopping match-all checks after a filter fails.
- Fixed tag-based filters ignoring NBT, durability, or enchantment constraints in some matching and amount checks.
- Fixed the raw NBT editor not accepting input or reliably saving changes when pressing Enter or clicking outside it.
- Fixed remapped interaction keys interrupting network name and color editing.
- Moved filter configuration and wrench state to data components, with migration for existing data.
- Removed hidden faces from computer and node models.
- Updated English guides and control hints for filters, scanning, access settings, distribution, mass placement, and `.lnet` save/load.
