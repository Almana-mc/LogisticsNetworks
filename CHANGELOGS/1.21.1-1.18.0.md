## Feature Additions

- Channels can now carry items, fluids, energy, chemicals and Source at the same time. The Type row is now Resources: switch each kind on or off and give it its own batch. New channels carry everything they can; existing channels keep their old type
- Filters now hold items, fluids and chemicals together, and a whitelist only limits the kinds it lists
- Added ars energistique support
- Added the Recipe Card: write a recipe on it (JEI/EMI + button or by hand) with items, fluids and Mekanism chemicals, put it in any filter like any other entry, and the channel sends only whole recipe sets (every resource together) in every distribution mode, with an optional Blocking mode. The card's kinds must be switched on in Resources at both ends, and whole sets per operation are set on the Recipe sets line of the Resources popover
- Recipe Card ingredients can now target receiver slots: press S next to an item to list slots, and right-click it to split the count evenly over them, so machines like the vanilla Crafter get an exact layout
- ComputerCraft: getChannels entries and watch samples gain `types`, and samples gain `totals` per type; `type` and `total` now describe the first type
- Added a built-in "Original Textures" resource pack that restores the pre-1.17.1 upgrade and wrench textures
- Added sounds for button click's in mod's GUIs
- Nodes with a Network Upgrade on an AE2 ME Interface that has nothing configured can now pull anything from the whole ME network. Configure the Interface to limit what they can take (thanks Qther)
- Removing a node with the wrench or by breaking the block it sits on now puts the node and its upgrades straight into your inventory, dropping only what doesn't fit (thanks Qther)
- Creative players no longer use up nodes when placing them with the wrench, or upgrades when pasting a wrench clipboard (thanks Qther)
- New Logistics Node look: a flat frame texture on the item, the helmet and placed nodes, with connected nodes outlined as one shape. A lone node on a full block now draws 6 quads instead of 48, and the item model no longer z-fights (#126)

## Bug Fixes

- Logistics Nodes no longer show up as entity dots on Xaero's Minimap and World Map radar (#148)
- Nodes joining a label now get the label's latest settings instead of the ones it had when it was created (#149)
- Block icons in the graph editor no longer draw on top of the node hover tooltip
- Labeled nodes that were unloaded while the label was edited now pick up the changes when they load
- Pasting a wrench clipboard onto a node now gives it its label's current settings instead of the clipboard's
- Crafting a wrench on its own now resets it, clearing a storage link left behind by a removed AE2 or RS network (#153)
- Improved performance when exporting from large inventories such as Functional Storage controllers to many filtered receivers
- Equal Distribution now splits what the sender actually has instead of the full batch size, so 10 items over 10 receivers gives 1 each instead of all 10 to the first
- Equal Distribution now splits fluid, energy, chemical and Source channels too, instead of acting like Priority
- Number keys now swap hotbar items into the node screen's slots, so upgrades can be hotkeyed in (#171)
- Text typed into the priority, tick delay and label boxes is now readable in light themes such as Brutalist (#161)
- Network Upgrade now works on ExtendedAE's Extended Interface part (#170)
- Network Upgrade now works on Cable Tiers interfaces, so they reach the whole Refined Storage network instead of only their own buffer
